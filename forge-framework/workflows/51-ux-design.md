# Workflow 51: User Experience Design

**Duration**: 4-20h | **Outputs**: UX strategy, user research, wireframes, prototypes, usability report

## Trigger

- New product design, UX redesign
- User research initiative, usability improvement
- Design system creation, accessibility improvement
- Mobile experience optimization, conversion optimization

## Steps

### Step 1: User Research
**Actions**: Define research objectives, select research methods, recruit participants, conduct research, analyze findings.
**Methods**: Interviews, surveys, contextual inquiry, diary studies, analytics review.
**Output**: User research report | **Time**: 2-4h | **Tools**: Research tools, analytics platforms
| QG1 | Research objectives defined |
| QG2 | Research conducted |
| QG3 | Findings analyzed |
| QG4 | Personas created |
| QG5 | Journey maps created |
| QG6 | Usability tested |

## Decision Points

| Point | Options | Criteria |
|-------|---------|----------|
| DP1: Research method? | Qualitative / Quantitative / Mixed | Research objectives, timeline |
| DP2: Design approach? | Mobile-first / Desktop-first / Responsive | User demographics, context |
| DP3: Prototyping fidelity? | Low / Medium / High | Timeline, fidelity needs |
| DP4: Testing approach? | Moderated / Unmoderated | Budget, timeline, complexity |

## Anti-Patterns

1. **Designing for yourself** — Not considering users
2. **Feature creep** — Adding without purpose
3. **Ignoring accessibility** — Not designing for all
4. **Pixel-perfect syndrome** — Focusing on visuals over usability

## Edge Cases

- Diverse user groups: Design for all personas
- Limited research time: Use lean UX methods
- Legacy constraints: Design within constraints
- Multi-platform: Design consistent experiences
