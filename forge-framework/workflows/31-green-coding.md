# Workflow 31: Green Coding

**Duration**: 2-8h | **Outputs**: Carbon audit, optimization plan, sustainability report

## Trigger
- Sustainability initiative, carbon footprint reduction
- ESG compliance, green software certification

## Steps

### Step 1: Carbon Baseline
Measure current carbon footprint. Identify high-impact areas.
**Time**: 1-2h.

### Step 2: Code Analysis
Analyze energy-efficient patterns. Identify inefficient algorithms and queries.
**Time**: 2-4h.

### Step 3: Optimization Strategy
Define green coding practices. Plan resource right-sizing. Identify serverless opportunities.
**Time**: 1-2h.

### Step 4: Implementation
Optimize algorithms. Reduce data transfer. Implement caching.
**Time**: 2-4h.

### Step 5: Measurement
Track carbon reduction. Compare against baseline. Document savings.
**Time**: 1-2h.

### Step 6: Reporting
Document carbon footprint, optimizations, ongoing plan.
**Time**: 30-60 min.

## Quality Gates

| Gate | Criteria |
|------|----------|
| QG1 | Baseline established |
| QG2 | Code analyzed |
| QG3 | Strategy defined |
| QG4 | Optimizations implemented |
| QG5 | Reduction measured |
| QG6 | Report complete |

## Anti-Patterns

1. **Greenwashing** — Claims without substance
2. **Premature optimization** — Complexity for marginal gains
3. **Metric obsession** — Wrong metrics optimized
4. **Ignoring trade-offs** — Sustainability vs. performance

## Edge Cases

- Embodied carbon: Hardware lifecycle
- Data center location: Grid carbon intensity
- Remote work: Travel vs. datacenter
- Circular economy: E-waste considerations
