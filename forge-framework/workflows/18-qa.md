# Workflow 18: Quality Assurance

**Duration**: 4-16h | **Outputs**: QA strategy, test automation plan, process improvement

## Trigger

- QA strategy definition, test automation planning, process improvement
- Quality metrics analysis, QA audit

## Steps

### Step 1: QA Strategy Definition
Define QA goals, scope, approach. Align with business objectives.
**Time**: 1-2h.

### Step 2: Process Assessment
Assess current QA processes. Identify gaps and inefficiencies.
**Time**: 2-4h.

### Step 3: Test Automation Planning
Identify automation opportunities. Define automation strategy and tools.
**Time**: 2-4h.

### Step 4: Metrics Definition
Define quality metrics (defect density, escape rate, coverage). Establish targets.
**Time**: 1-2h.

### Step 5: Process Improvement
Identify and implement improvements. Update processes and templates.
**Time**: 2-4h.

### Step 6: Reporting
Document strategy, improvements, metrics. Present to stakeholders.
**Time**: 1-2h.

## Quality Gates

| Gate | Criteria |
|------|----------|
| QG1 | Strategy defined |
| QG2 | Process assessed |
| QG3 | Automation planned |
| QG4 | Metrics defined |
| QG5 | Improvements documented |
| QG6 | Report follows template |

## Anti-Patterns

1. **100% automation myth** — Some tests require manual
2. **Coverage vanity** — High % but low value
3. **Ignored flaky tests** — Erodes confidence
4. **One-size-fits-all** — Same approach for all projects

## Edge Cases

- Legacy systems: Gradual test coverage
- Third-party APIs: Mock appropriately
- Performance tests: Isolated environment
- Security tests: Controlled scope

## Output

Use: `templates/qa-strategy.md` | Capability: `capabilities/quality-assurance.md`

## Anti-Patterns

1. **Writing for yourself** — Not considering audience needs
2. **No review** — Publishing without technical review
3. **Outdated docs** — Not maintaining documentation
4. **No examples** — Abstract explanations without examples

## Edge Cases

- Multiple audiences → Create separate documents per audience
- No existing template → Adapt from similar project
- Technical reviewer unavailable → Use peer review
