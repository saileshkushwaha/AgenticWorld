# Analysis Capability

## Definition

The ability to evaluate requirements, assess feasibility, identify risks, and perform trade-off analysis to inform decision-making.

## Scope

### In Scope
- Requirements analysis (functional and non-functional)
- Feasibility assessment (technical, economic, operational)
- Risk identification and assessment
- Constraint documentation
- Trade-off analysis
- SWOT analysis
- Cost-benefit analysis
- Decision matrix creation

### Out of Scope
- Implementation of analyzed solutions (see Implementation capability)
- Market research (see Research capability)
- Financial modeling (consult finance experts)

## Skills

### Requirements Engineering
- Requirements elicitation and documentation
- Requirements classification and prioritization
- Requirements validation and verification
- Acceptance criteria definition
- Traceability matrix creation

### Feasibility Assessment
- Technical feasibility evaluation
- Economic feasibility calculation
- Operational feasibility assessment
- Timeline feasibility analysis
- Resource feasibility evaluation

### Risk Management
- Risk identification (technical, operational, business)
- Risk assessment (probability, impact, score)
- Risk prioritization
- Mitigation strategy development
- Contingency planning

### Trade-off Analysis
- Criteria definition and weighting
- Option scoring and comparison
- Pareto analysis
- Decision matrix construction
- Sensitivity analysis

## Inputs
- Project objectives and context
- Stakeholder requirements
- Research findings
- Constraints and assumptions
- Historical data

## Outputs
- Requirements document
- Feasibility assessment report
- Risk register
- Trade-off analysis document
- Recommendations with rationale

## Quality Criteria
- All requirement types addressed
- Requirements are testable and unambiguous
- Feasibility assessed across all dimensions
- Risks identified with mitigation strategies
- Trade-offs analyzed with clear rationale

## Metrics
- Requirements coverage (%)
- Risk coverage (% of identified risks mitigated)
- Feasibility confidence level
- Stakeholder agreement level
- Analysis completeness score
