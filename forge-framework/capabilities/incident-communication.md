# Incident Communication Capability

## Definition
The ability to plan and execute communications during incidents to stakeholders, customers, and regulators.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can send pre-defined notification templates |
| 2 | Competent | Can draft incident communications |
| 3 | Proficient | Can manage incident communication programs |
| 4 | Expert | Can handle complex multi-stakeholder communications |
| 5 | Master | Can establish organizational incident communication practices |

## Scope
**In Scope**: Communication planning, stakeholder notification, status updates, post-incident communication
**Out of Scope**: Public relations strategy, marketing communications

## Skills
- **Planning**: Stakeholder identification, channel selection, message templates
- **Execution**: Timely notification, regular updates, transparent communication
- **Audience**: Technical translation, executive summaries, customer messaging
- **Compliance**: Regulatory notification, legal review, documentation

## Quality Criteria
- Communication plan created
- Initial notification sent within SLA
- Regular updates provided
- Post-incident report delivered
