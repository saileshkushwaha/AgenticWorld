# Domain-Driven Design Capability

## Definition
The ability to apply domain-driven design principles for complex domain modeling.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can understand basic DDD concepts |
| 2 | Competent | Can identify bounded contexts |
| 3 | Proficient | Can apply strategic and tactical DDD patterns |
| 4 | Expert | Can lead DDD initiatives for complex domains |
| 5 | Master | Can establish organizational DDD practices |

## Scope
**In Scope**: Domain discovery, bounded contexts, ubiquitous language, strategic design, tactical design
**Out of Scope**: Implementation, database design

## Skills
- **Discovery**: Event storming, domain storytelling, expert interviews
- **Strategic**: Bounded contexts, context maps, ubiquitous language
- **Tactical**: Aggregates, entities, value objects, domain events
- **Validation**: Model validation, iterative refinement

## Quality Criteria
- Domain discovered and documented
- Ubiquitous language defined
- Bounded contexts identified
- Model validated with experts
