# Productivity Metrics Capability

## Definition
The ability to define, collect, analyze, and act on productivity metrics to measure and improve engineering team performance.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can collect basic metrics |
| 2 | Competent | Can implement DORA metrics |
| 3 | Proficient | Can design productivity frameworks |
| 4 | Expert | Can design enterprise measurement systems |
| 5 | Master | Can establish organizational productivity culture |

## Scope
**In Scope**: DORA metrics, flow metrics, quality metrics, developer experience, ROI analysis
**Out of Scope**: Individual performance evaluation, compensation decisions

## Skills
- **DORA Metrics**: Deployment frequency, lead time, MTTR, change failure rate
- **Flow Metrics**: WIP, cycle time, throughput, flow efficiency
- **Quality Metrics**: Defect density, escape rate, coverage
- **ROI Analysis**: Time savings, quality improvements, productivity gains

## Quality Criteria
- Metrics framework defined
- Data collection automated where possible
- Dashboards provide actionable insights
- ROI analysis demonstrates value
