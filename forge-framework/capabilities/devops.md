# DevOps Capability

## Definition
The ability to design and implement DevOps practices that bridge development and operations to deliver software faster and more reliably.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can use CI/CD tools |
| 2 | Competent | Can design CI/CD pipelines |
| 3 | Proficient | Can implement DevOps transformations |
| 4 | Expert | Can design enterprise DevOps strategies |
| 5 | Master | Can establish DevOps culture |

## Scope
**In Scope**: CI/CD, automation, monitoring, collaboration, continuous improvement
**Out of Scope**: Security integration (use DevSecOps), infrastructure provisioning (use IaC)

## Skills
- **CI/CD**: Pipeline design, build automation, deployment automation
- **Automation**: Test automation, infrastructure automation, monitoring automation
- **Monitoring**: Application monitoring, infrastructure monitoring, log management
- **Collaboration**: Team alignment, communication, knowledge sharing

## Quality Criteria
- Deployment frequency improved
- Lead time for changes reduced
- Mean time to recovery reduced
- Change failure rate reduced
