# Service Mesh Capability

## Definition
The ability to implement and manage service mesh for microservices networking, security, and observability.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can understand service mesh concepts |
| 2 | Competent | Can configure sidecar injection |
| 3 | Proficient | Can implement service mesh with mTLS |
| 4 | Expert | Can manage multi-cluster service mesh |
| 5 | Master | Can establish organizational mesh strategy |

## Scope
**In Scope**: Traffic management, mTLS, observability, policy enforcement, multi-cluster
**Out of Scope**: Application development, container orchestration

## Skills
- **Traffic**: Routing, splitting, retries, circuit breaking
- **Security**: mTLS, authorization, certificate management
- **Observability**: Tracing, metrics, access logs
- **Operations**: Installation, upgrades, troubleshooting

## Quality Criteria
- Mesh installed and configured
- mTLS enforced
- Observability operational
- Traffic policies active
