# Data Governance Capability

## Definition
The ability to establish and maintain data governance frameworks ensuring data quality, security, and compliance.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can follow data governance policies |
| 2 | Competent | Can contribute to data quality initiatives |
| 3 | Proficient | Can design data governance frameworks |
| 4 | Expert | Can lead enterprise data governance programs |
| 5 | Master | Can establish organizational data governance practices |

## Scope
**In Scope**: Data inventory, quality management, access controls, lineage, catalog, compliance
**Out of Scope**: Data analytics, business intelligence implementation

## Skills
- **Governance**: Policy development, stewardship, decision rights
- **Quality**: Quality dimensions, checks, metrics, remediation
- **Privacy**: Classification, anonymization, retention, deletion
- **Tools**: Data catalog, lineage tools, quality platforms

## Quality Criteria
- Data assets inventoried
- Quality standards established
- Access controls implemented
- Compliance monitoring active
