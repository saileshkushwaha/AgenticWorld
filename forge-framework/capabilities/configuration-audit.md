# Configuration Audit Capability

## Definition
The ability to evaluate system configurations against security baselines, compliance requirements, and operational standards.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can perform basic configuration checks |
| 2 | Competent | Can conduct configuration audits |
| 3 | Proficient | Can lead configuration management initiatives |
| 4 | Expert | Can design configuration audit frameworks |
| 5 | Master | Can establish configuration governance culture |

## Scope
**In Scope**: Configuration baselines, drift detection, compliance assessment, change validation
**Out of Scope**: Hardware configuration, physical infrastructure

## Skills
- **Baseline Management**: Baseline definition, maintenance, comparison
- **Drift Detection**: Automated scanning, manual verification
- **Compliance Assessment**: CIS benchmarks, STIGs, custom standards
- **Remediation**: Configuration correction, automation

## Quality Criteria
- Baselines clearly defined
- Audit methodology documented
- Findings accurately documented
- Remediation tracked to completion
