# Platform Engineering Capability

## Definition
The ability to design and implement internal developer platforms that improve developer productivity.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can use platform tools |
| 2 | Competent | Can contribute to platform development |
| 3 | Proficient | Can design platform capabilities |
| 4 | Expert | Can lead enterprise platform initiatives |
| 5 | Master | Can establish organizational platform strategy |

## Scope
**In Scope**: Self-service portal, golden paths, developer workflows, platform operations
**Out of Scope**: Application development, infrastructure provisioning

## Skills
- **Portal**: Service catalog, templates, documentation
- **Golden Paths**: Paved roads, templates, guardrails
- **Operations**: Platform monitoring, support, SLOs
- **Adoption**: Champions, feedback, metrics

## Quality Criteria
- Self-service portal operational
- Golden paths implemented
- Adoption metrics tracked
- Developer satisfaction improved
