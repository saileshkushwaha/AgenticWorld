# Network Security Capability

## Definition
The ability to design, implement, and manage network security controls including firewalls, segmentation, and monitoring.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can configure basic firewall rules |
| 2 | Competent | Can implement network segmentation |
| 3 | Proficient | Can design enterprise network security architecture |
| 4 | Expert | Can implement zero trust network architecture |
| 5 | Master | Can establish organizational network security practices |

## Scope
**In Scope**: Firewall configuration, network segmentation, VPN, IDS/IPS, zero trust networking
**Out of Scope**: Physical security, endpoint security

## Skills
- **Firewall**: Rule design, NAT, stateful inspection
- **Segmentation**: VLANs, micro-segmentation, trust zones
- **VPN**: Site-to-site, remote access, encryption
- **Monitoring**: IDS/IPS, traffic analysis, anomaly detection

## Quality Criteria
- Network topology documented
- Segmentation implemented
- Monitoring active
- Compliance requirements met
