# User Experience Design Capability

## Definition
The ability to design user experiences that are intuitive, accessible, and delightful while meeting business objectives.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can create basic wireframes |
| 2 | Competent | Can design user interfaces |
| 3 | Proficient | Can design UX strategies |
| 4 | Expert | Can design enterprise UX platforms |
| 5 | Master | Can establish UX culture |

## Scope
**In Scope**: User research, interaction design, visual design, prototyping, usability testing
**Out of Scope**: Accessibility audit (use Accessibility), front-end development (use Implementation)

## Skills
- **User Research**: Interviews, surveys, personas, journey mapping
- **Interaction Design**: Wireframing, prototyping, information architecture
- **Visual Design**: Typography, color theory, layout
- **Usability Testing**: Planning, execution, analysis

## Quality Criteria
- User research conducted
- Personas and journey maps created
- Prototypes tested with users
- Accessibility requirements met
