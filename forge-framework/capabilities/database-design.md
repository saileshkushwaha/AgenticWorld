# Database Design Capability

## Definition
The ability to design database schemas that are normalized, performant, and scalable while meeting application requirements.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can create basic tables |
| 2 | Competent | Can design normalized schemas |
| 3 | Proficient | Can design database architectures |
| 4 | Expert | Can design enterprise data platforms |
| 5 | Master | Can establish data architecture culture |

## Scope
**In Scope**: Data modeling, schema design, indexing, migration, performance optimization
**Out of Scope**: Data migration execution (use Data Migration), data quality audit (use Data Audit)

## Skills
- **Data Modeling**: ER modeling, normalization, denormalization
- **Schema Design**: Data types, constraints, indexes
- **Performance**: Query optimization, indexing, partitioning
- **Migration**: Strategy, execution, validation

## Quality Criteria
- Schema normalized appropriately
- Indexes optimized for queries
- Migration plan documented
- Performance benchmarks established
