# API Gateway Capability

## Definition
The ability to design, implement, and manage API gateways for routing, security, and analytics.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can configure basic API routes |
| 2 | Competent | Can implement rate limiting and authentication |
| 3 | Proficient | Can design API gateway architecture |
| 4 | Expert | Can implement multi-region API management |
| 5 | Master | Can establish organizational API platform |

## Scope
**In Scope**: Routing, transformation, rate limiting, authentication, analytics, developer portal
**Out of Scope**: API design, backend implementation

## Skills
- **Routing**: Path-based, header-based, weighted routing
- **Security**: API keys, OAuth, rate limiting, IP filtering
- **Analytics**: Usage metrics, latency tracking, error rates
- **Portal**: Documentation, SDK generation, sandbox

## Quality Criteria
- Gateway configured
- Security policies active
- Analytics operational
- Developer portal live
