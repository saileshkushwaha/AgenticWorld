# API Design Capability

## Definition
The ability to design APIs that are usable, scalable, and maintainable while providing excellent developer experience.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can document APIs |
| 2 | Competent | Can design REST APIs |
| 3 | Proficient | Can design API strategies |
| 4 | Expert | Can design enterprise API platforms |
| 5 | Master | Can establish API-first culture |

## Scope
**In Scope**: API architecture, specification, security, developer experience, governance
**Out of Scope**: API management (use API Management), API integration (use Implementation)

## Skills
- **API Architecture**: REST, GraphQL, gRPC design
- **Specification**: OpenAPI, AsyncAPI, GraphQL Schema
- **Security**: Authentication, authorization, rate limiting
- **Developer Experience**: Documentation, SDKs, sandbox

## Quality Criteria
- API specification complete
- Security design implemented
- Developer experience excellent
- Governance framework established
