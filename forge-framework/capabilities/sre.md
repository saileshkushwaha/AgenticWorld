# SRE Capability

## Definition
The ability to implement Site Reliability Engineering practices to ensure systems are reliable, scalable, and efficient.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can monitor system reliability |
| 2 | Competent | Can define SLOs and error budgets |
| 3 | Proficient | Can implement SRE practices |
| 4 | Expert | Can design enterprise SRE strategies |
| 5 | Master | Can establish SRE culture |

## Scope
**In Scope**: SLOs, error budgets, incident management, capacity planning, toil reduction
**Out of Scope**: Security incidents (use Incident Management), performance optimization (use Performance)

## Skills
- **SLO Definition**: SLI selection, objective setting, error budget calculation
- **Incident Management**: Response process, postmortem, runbooks
- **Capacity Planning**: Trend analysis, forecasting, scaling
- **Toil Reduction**: Identification, automation, measurement

## Quality Criteria
- SLOs defined and monitored
- Error budgets enforced
- Incident response process established
- Capacity plan current
- Toil reduction ongoing
