# Implementation Capability

## Definition

The ability to translate designs into working code through clean coding practices, unit testing, and integration.

## Scope

### In Scope
- Clean, maintainable code production
- Unit test development
- Integration implementation
- Code review participation
- Refactoring and optimization
- Error handling implementation
- Logging and monitoring integration
- Documentation of code

### Out of Scope
- Architecture design (see Design capability)
- Test strategy and planning (see Testing capability)
- Infrastructure setup (see Deployment capability)

## Skills

### Coding
- Language proficiency (multiple languages)
- Coding standards adherence
- Design pattern application
- Clean code practices
- Defensive programming
- Error handling
- Performance optimization

### Testing (Unit)
- Test-driven development (TDD)
- Test case design
- Mocking and stubbing
- Test isolation
- Coverage analysis
- Test maintainability

### Integration
- API implementation
- Database integration
- External service integration
- Message queue integration
- Error handling across boundaries
- Data transformation

### Code Review
- Constructive feedback
- Standards enforcement
- Security review
- Performance review
- Maintainability assessment

## Inputs
- Design documents
- API specifications
- Data models
- Coding standards
- Requirements (for context)

## Outputs
- Source code
- Unit test suite
- Code review comments
- Integration code
- Technical documentation

## Quality Criteria
- Code follows standards and conventions
- Unit tests written and passing
- Code reviewed and approved
- Integration tests passing
- Code coverage meets targets
- No critical or high bugs open

## Related Workflows
- `workflows/04-implement.md` - Primary workflow
- `workflows/03-design.md` - Provides input
- `workflows/05-test.md` - Uses implementation outputs

## Metrics
- Code coverage (%)
- Code quality score (static analysis)
- Bug density (bugs per LOC)
- Review turnaround time
- Build success rate
