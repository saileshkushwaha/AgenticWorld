# Distributed Tracing Capability

## Definition
The ability to implement and analyze distributed tracing for microservices observability.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can view traces in tracing UI |
| 2 | Competent | Can add basic instrumentation to services |
| 3 | Proficient | Can design distributed tracing architectures |
| 4 | Expert | Can implement enterprise-wide tracing solutions |
| 5 | Master | Can establish organizational tracing practices |

## Scope
**In Scope**: Instrumentation, context propagation, trace analysis, performance insights
**Out of Scope**: Log aggregation, metrics collection

## Skills
- **Instrumentation**: Auto-instrumentation, manual instrumentation, context propagation
- **Analysis**: Trace visualization, latency analysis, dependency mapping
- **Sampling**: Head-based, tail-based, adaptive sampling
- **Integration**: Correlation with logs and metrics

## Quality Criteria
- Services instrumented
- Context propagated across services
- Sampling strategy defined
- Analysis queries created
