# Developer Experience Capability

## Definition
The ability to assess and improve developer experience through tooling, processes, and culture.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can provide feedback on developer tools |
| 2 | Competent | Can identify and address DX friction points |
| 3 | Proficient | Can design DX improvement programs |
| 4 | Expert | Can lead enterprise DX transformation |
| 5 | Master | Can establish organizational DX practices |

## Scope
**In Scope**: Tooling, onboarding, environment, feedback, metrics
**Out of Scope**: HR policies, compensation, hiring

## Skills
- **Assessment**: Surveys, interviews, metrics
- **Tooling**: IDE, CI/CD, local development
- **Onboarding**: Documentation, buddy system, time-to-commit
- **Measurement**: NPS, DORA, SPACE metrics

## Quality Criteria
- DX baseline established
- Improvement roadmap created
- Feedback channels active
- Metrics tracked and improving
