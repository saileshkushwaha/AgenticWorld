# A/B Testing Capability

## Definition
The ability to design, implement, and analyze A/B tests for data-driven decision making.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can interpret A/B test results |
| 2 | Competent | Can implement basic A/B tests |
| 3 | Proficient | Can design and analyze A/B tests |
| 4 | Expert | Can lead experimentation programs |
| 5 | Master | Can establish organizational experimentation practices |

## Scope
**In Scope**: Experiment design, implementation, analysis, decision framework
**Out of Scope**: Feature flag infrastructure, analytics platform

## Skills
- **Design**: Hypothesis creation, metric selection, sample size calculation
- **Implementation**: Feature flag integration, tracking, variant management
- **Analysis**: Statistical significance, segment analysis, decision making
- **Ethics**: User consent, ethical considerations, bias detection

## Quality Criteria
- Hypothesis defined
- Sample size calculated
- Results analyzed for significance
- Decision documented
