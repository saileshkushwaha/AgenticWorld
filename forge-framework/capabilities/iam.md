# Identity and Access Management Capability

## Definition
The ability to manage digital identities, authentication, authorization, and access control across systems.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can configure basic user accounts and passwords |
| 2 | Competent | Can implement SSO and basic RBAC |
| 3 | Proficient | Can design IAM architecture with MFA and lifecycle management |
| 4 | Expert | Can implement zero-trust IAM with adaptive authentication |
| 5 | Master | Can establish organizational IAM practices and governance |

## Scope
**In Scope**: Authentication, authorization, SSO, MFA, RBAC, lifecycle management, identity governance
**Out of Scope**: Physical access control, biometric systems

## Skills
- **Authentication**: SSO, MFA, passwordless, adaptive authentication
- **Authorization**: RBAC, ABAC, policy-based access
- **Identity Lifecycle**: Provisioning, deprovisioning, access reviews
- **Standards**: SAML, OIDC, OAuth 2.0, SCIM

## Quality Criteria
- Identity stores consolidated
- SSO implemented for all applications
- MFA enforced for privileged access
- Lifecycle management automated
