# AutoDoc Generation Capability

## Definition
The ability to automatically generate documentation from source code, annotations, and API definitions using documentation generation tools.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can run existing documentation generators with basic configuration |
| 2 | Competent | Can configure documentation generators for standard codebases |
| 3 | Proficient | Can customize templates, plugins, and output formats for complex projects |
| 4 | Expert | Can establish documentation generation pipelines and integrate with CI/CD |
| 5 | Master | Can create custom documentation generators and establish organizational documentation standards |

## Scope
**In Scope**: Source code analysis, documentation generation, output validation, publishing
**Out of Scope**: Manual documentation writing, content creation, graphical diagram creation

## Skills
- **Documentation Tools**: Swagger/OpenAPI, Javadoc, Doxygen, Sphinx, TypeDoc, ESDoc, Haddoc
- **Configuration**: Tool configuration, template customization, plugin management
- **Code Analysis**: Annotation parsing, comment extraction, structural analysis
- **Output Formats**: HTML, Markdown, PDF, JSON, OpenAPI/Specification formats
- **Quality Assurance**: Coverage analysis, link validation, example testing
- **Integration**: CI/CD pipelines, version control, artifact publishing

## Quality Criteria
- Source analyzed for documentable elements
- Documentation tool configured appropriately
- Documentation generated without errors
- Output validated for accuracy and completeness
- Documentation published and accessible
