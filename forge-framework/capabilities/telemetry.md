# Telemetry Capability

## Definition
The ability to capture, analyze, and act on workflow execution data to enable continuous improvement and operational insights.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Emit basic workflow start/complete events |
| 2 | Competent | Configure telemetry levels, export formats |
| 3 | Proficient | Analyze telemetry data, derive metrics |
| 4 | Expert | Design telemetry systems, create dashboards |
| 5 | Master | Establish organizational observability culture |

## Scope
**In Scope**: Event capture, metrics derivation, analytics, dashboard design
**Out of Scope**: Tool administration, data retention policy

## Skills
- **Event Design**: Define event types, schema, emission points
- **Data Analysis**: Calculate quality metrics, trends, correlations
- **Visualization**: Create dashboards, real-time monitoring
- **Improvement**: Identify workflow improvements from data

## Quality Criteria
- Telemetry system configured
- Events captured consistently
- Analytics generated
- Improvements identified
