# Secure Data Handling Capability

## Definition
The ability to implement comprehensive data security controls for data at rest and in transit.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can implement basic data handling procedures |
| 2 | Competent | Can manage data classification and access controls |
| 3 | Proficient | Can design data security architectures |
| 4 | Expert | Can implement enterprise-grade data security |
| 5 | Master | Can establish organizational data security culture |

## Scope
**In Scope**: Data classification, access control, encryption, secure data handling procedures
**Out of Scope**: Hardware security modules, physical security controls

## Skills
- **Data Classification**: Classify data according to sensitivity
- **Access Control**: Implement role-based access controls
- **Encryption**: Implement encryption for data at rest and in transit
- **Incident Response**: Respond to data security incidents

## Quality Criteria
- Data properly classified
- Access controls properly implemented
- Encryption properly applied
- Incident response procedures documented
