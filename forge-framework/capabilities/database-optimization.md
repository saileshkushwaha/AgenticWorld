# Database Optimization Capability

## Definition
The ability to analyze and optimize database performance through query tuning, indexing, and configuration.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can identify slow queries |
| 2 | Competent | Can add basic indexes and optimize simple queries |
| 3 | Proficient | Can design comprehensive optimization strategies |
| 4 | Expert | Can lead enterprise database optimization initiatives |
| 5 | Master | Can establish organizational database optimization practices |

## Scope
**In Scope**: Query analysis, index strategy, schema optimization, configuration tuning
**Out of Scope**: Database migration, database administration

## Skills
- **Analysis**: Slow query log, execution plans, profiling
- **Indexing**: B-tree, hash, partial, covering indexes
- **Schema**: Normalization, denormalization, partitioning
- **Configuration**: Connection pooling, buffer tuning, parallelism

## Quality Criteria
- Baseline established
- Queries analyzed
- Index strategy defined
- Improvements validated
