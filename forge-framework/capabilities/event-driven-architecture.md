# Event-Driven Architecture Capability

## Definition
The ability to design and implement event-driven systems including event modeling, messaging, and stream processing.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can publish and consume events |
| 2 | Competent | Can implement event-driven patterns |
| 3 | Proficient | Can design event-driven architectures |
| 4 | Expert | Can implement event sourcing and CQRS |
| 5 | Master | Can establish organizational event strategy |

## Scope
**In Scope**: Event modeling, messaging, schema registry, stream processing, event sourcing
**Out of Scope**: Database design, API design

## Skills
- **Modeling**: Domain events, event versioning, schema design
- **Messaging**: Kafka, RabbitMQ, message patterns
- **Processing**: Stream processing, windowing, exactly-once
- **Governance**: Schema registry, compatibility, evolution

## Quality Criteria
- Events modeled and versioned
- Broker configured
- Schema registry active
- Monitoring operational
