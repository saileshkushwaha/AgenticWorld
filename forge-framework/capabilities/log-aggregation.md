# Log Aggregation Capability

## Definition
The ability to design and implement log aggregation and analysis solutions for observability.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can query centralized logs |
| 2 | Competent | Can configure log shipping and basic parsing |
| 3 | Proficient | Can design log aggregation architectures |
| 4 | Expert | Can implement enterprise-wide log management |
| 5 | Master | Can establish organizational logging practices |

## Scope
**In Scope**: Log collection, parsing, storage, analysis, alerting, retention
**Out of Scope**: Application performance monitoring, distributed tracing

## Skills
- **Collection**: Log shipping, agents, API ingestion
- **Parsing**: Regex, JSON parsing, field extraction, normalization
- **Storage**: Indexing, retention tiers, archival
- **Analysis**: Query languages, dashboards, pattern detection

## Quality Criteria
- All log sources aggregated
- Parsing rules implemented
- Retention policies defined
- Alerts configured
