# Microservices Decomposition Capability

## Definition
The ability to analyze monolithic applications and decompose them into microservices.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can identify potential service boundaries |
| 2 | Competent | Can assist in decomposition activities |
| 3 | Proficient | Can design decomposition strategies |
| 4 | Expert | Can lead complex decomposition initiatives |
| 5 | Master | Can establish organizational decomposition practices |

## Scope
**In Scope**: Domain analysis, boundary design, migration planning, API contracts
**Out of Scope**: Container orchestration, service mesh implementation

## Skills
- **Analysis**: Domain-driven design, dependency mapping, coupling assessment
- **Design**: Service boundaries, API contracts, data ownership
- **Migration**: Strangler fig, branch by abstraction, incremental extraction
- **Validation**: Functional equivalence, performance comparison

## Quality Criteria
- Domains identified and mapped
- Service boundaries defined
- Migration plan created
- API contracts designed
