# Communication Capability

## Definition
The ability to communicate effectively across different audiences, formats, and contexts throughout the software development lifecycle.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can write basic status updates |
| 2 | Competent | Can create technical reports and presentations |
| 3 | Proficient | Can adapt communication for various audiences |
| 4 | Expert | Can lead technical discussions and decision-making |
| 5 | Master | Can establish team communication culture |

## Scope
**In Scope**: Status reports, technical reports, presentations, decision docs, stakeholder updates
**Out of Scope**: Marketing communications, customer support

## Skills
- **Audience Analysis**: Identifying stakeholders, technical levels, information needs
- **Technical Writing**: Reports, documentation, specifications
- **Presentation**: Slides, demos, walkthroughs
- **Stakeholder Management**: Updates, negotiations, alignment

## Quality Criteria
- Audience needs addressed
- Key messages clear
- Format appropriate for context
- Feedback collected and incorporated
