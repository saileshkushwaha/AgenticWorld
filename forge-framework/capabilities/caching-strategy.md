# Caching Strategy Capability

## Definition
The ability to design and implement caching strategies for performance optimization.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can use existing caching configurations |
| 2 | Competent | Can implement basic caching patterns |
| 3 | Proficient | Can design comprehensive caching strategies |
| 4 | Expert | Can implement enterprise-wide caching solutions |
| 5 | Master | Can establish organizational caching practices |

## Scope
**In Scope**: Cache architecture, invalidation strategies, performance optimization
**Out of Scope**: CDN configuration, database query caching

## Skills
- **Architecture**: Cache layers, topology, scaling
- **Invalidation**: TTL, write-through, write-behind, event-based
- **Patterns**: Cache-aside, read-through, write-through, write-behind
- **Optimization**: Hit ratio, eviction policies, memory management

## Quality Criteria
- Workload analyzed
- Architecture designed
- Invalidation strategy defined
- Performance validated
