# Disaster Recovery Testing Capability

## Definition
The ability to plan, execute, and analyze disaster recovery tests validating recovery procedures.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can participate in DR tests |
| 2 | Competent | Can plan and execute basic DR tests |
| 3 | Proficient | Can design comprehensive DR test programs |
| 4 | Expert | Can lead enterprise-wide DR testing initiatives |
| 5 | Master | Can establish DR testing best practices |

## Scope
**In Scope**: Test planning, scenario design, execution, analysis, remediation
**Out of Scope**: Actual disaster response, insurance claims

## Skills
- **Planning**: Test design, scenario development, success criteria
- **Execution**: Test coordination, observation, documentation
- **Analysis**: Gap identification, root cause analysis, improvement planning
- **Communication**: Stakeholder updates, findings presentation

## Quality Criteria
- Test plan approved
- Scenarios executed safely
- Results documented
- Remediation tracked
