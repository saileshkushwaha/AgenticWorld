# Penetration Testing Capability

## Definition
The ability to plan, execute, and report on penetration tests simulating real-world attacks.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can run automated vulnerability scans |
| 2 | Competent | Can assist in penetration testing activities |
| 3 | Proficient | Can conduct penetration tests independently |
| 4 | Expert | Can lead complex penetration testing engagements |
| 5 | Master | Can establish organizational penetration testing programs |

## Scope
**In Scope**: Scope definition, reconnaissance, vulnerability identification, exploitation, reporting
**Out of Scope**: Social engineering (without authorization), physical security testing

## Skills
- **Reconnaissance**: OSINT, network scanning, service enumeration
- **Exploitation**: Web app attacks, network attacks, privilege escalation
- **Reporting**: Severity rating, remediation planning, executive communication
- **Tools**: Burp Suite, Metasploit, Nmap, custom scripts

## Quality Criteria
- Scope authorized in writing
- Findings documented with evidence
- Severity rated using CVSS
- Remediation roadmap provided
