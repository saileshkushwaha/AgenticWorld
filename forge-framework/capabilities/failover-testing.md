# Failover Testing Capability

## Definition
The ability to design, execute, and analyze failover tests validating high availability configurations.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can observe failover tests |
| 2 | Competent | Can execute planned failover tests |
| 3 | Proficient | Can design failover test strategies |
| 4 | Expert | Can lead complex multi-system failover testing |
| 5 | Master | Can establish organizational failover testing practices |

## Scope
**In Scope**: Test design, execution, performance validation, improvement identification
**Out of Scope**: Load testing, stress testing

## Skills
- **Design**: Test scenarios, success criteria, rollback procedures
- **Execution**: Controlled failover, monitoring, documentation
- **Analysis**: Performance comparison, SLO validation, improvement identification
- **Types**: Automatic failover, manual failover, partial failure

## Quality Criteria
- Test strategy defined
- Failover executed successfully
- Performance validated
- Improvements documented
