# Data Audit Capability

## Definition
The ability to evaluate data quality, integrity, security, and compliance across organizational data assets.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can perform basic data quality checks |
| 2 | Competent | Can conduct data audits |
| 3 | Proficient | Can lead data governance initiatives |
| 4 | Expert | Can design data audit frameworks |
| 5 | Master | Can establish organizational data culture |

## Scope
**In Scope**: Data quality, data integrity, data security, data compliance, data governance
**Out of Scope**: Data migration execution, database administration

## Skills
- **Data Quality Assessment**: Accuracy, completeness, consistency, timeliness
- **Data Profiling**: Pattern analysis, anomaly detection, statistical analysis
- **Data Security Assessment**: Access controls, encryption, masking
- **Compliance Assessment**: Regulatory compliance, data retention, privacy

## Quality Criteria
- Data quality dimensions assessed
- Audit methodology documented
- Findings supported by data evidence
- Recommendations actionable and prioritized
