# Infrastructure as Code Capability

## Definition
The ability to design and implement Infrastructure as Code practices to automate infrastructure provisioning and management.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can use IaC tools |
| 2 | Competent | Can write IaC templates |
| 3 | Proficient | Can implement IaC strategies |
| 4 | Expert | Can design enterprise IaC frameworks |
| 5 | Master | Can establish IaC culture |

## Scope
**In Scope**: Template development, state management, deployment pipelines, governance
**Out of Scope**: Application deployment (use Deployment), security policies (use DevSecOps)

## Skills
- **Template Development**: Modular design, reusability, testing
- **State Management**: Remote state, locking, backup
- **Pipeline Design**: Plan/apply workflow, approval gates
- **Governance**: Policy as code, compliance, audit

## Quality Criteria
- Infrastructure defined as code
- State managed securely
- Deployment pipeline automated
- Governance policies enforced
