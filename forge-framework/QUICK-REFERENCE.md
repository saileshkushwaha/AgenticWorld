## Quick Workflow Examples

### Research Workflow (01)
**Trigger**: Technology evaluation needed
**Output**: Research report, comparison matrix, best practices
**Key Steps**: Define objectives → Gather information → Evaluate options → Synthesize findings

### Security Audit Workflow (10)
**Trigger**: Security assessment needed
**Output**: Security audit report, risk assessment, remediation plan
**Key Steps**: Scope definition → Threat modeling → Vulnerability scanning → Risk assessment

### Design Document Workflow (03)
**Trigger**: Architecture needed
**Output**: Design document with architecture, components, APIs
**Key Steps**: Requirements traceability → Architecture design → Component design

### Implementation Workflow (04)
**Trigger**: Code needed
**Output**: Implementation plan, code, tests
**Key Steps**: Design review → Implementation → Testing → Integration

### AI-Augmented Development Workflow (79)
**Trigger**: Development acceleration needed
**Output**: AI-assisted code, tests, documentation
**Key Steps**: AI integration assessment → Model selection → Task definition → AI-assisted implementation

### Standard Artifact Structure
```markdown
# [Artifact Title]

**Created**: [ISO 8601 timestamp]
**Phase**: [Current workflow phase]
**Status**: [draft | review | approved]
**Author**: [Agent/Team name]
**Version**: [Semantic version]

---

## Executive Summary
[2-3 sentence overview]

## [Main Content Sections]
[Phase-specific content as defined in the template]

## Decisions & Rationale
| Decision | Options Considered | Rationale |
|----------|-------------------|-----------|

## Risks & Mitigations
| Risk | Probability | Impact | Mitigation |
|------|-------------|--------|------------|

## Assumptions / Open Issues / Next Steps / References
```
