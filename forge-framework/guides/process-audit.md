# Process Audit Guide - Forge Engineering Lifecycle Framework

## Overview
This guide provides procedures for conducting process audits within the Forge framework. It covers process evaluation, compliance assessment, and improvement identification.

## Process Audit Process

### 1. Audit Planning

#### Process Selection Criteria
| Criteria | Description |
|----------|-------------|
| Risk Level | High-risk processes first |
| Performance | Underperforming processes |
| Compliance | Regulated processes |
| Change | Recently changed processes |
| Complaint | Customer complaint areas |

#### Audit Planning Steps
1. Identify process to audit
2. Define audit objectives
3. Determine audit criteria
4. Select audit team
5. Develop audit plan
6. Prepare audit tools

### 2. Audit Execution

#### Process Mapping
| Symbol | Meaning |
|--------|---------|
| Oval | Start/End |
| Rectangle | Process step |
| Diamond | Decision point |
| Arrow | Flow direction |
| Document | Document creation |

#### Audit Techniques
| Technique | Description | Application |
|-----------|-------------|-------------|
| Walkthrough | Following process flow | Understanding process |
| Observation | Watching operations | Validating practices |
| Interview | Talking to participants | Understanding execution |
| Document Review | Examining records | Verifying compliance |
| Sampling | Statistical sampling | Large populations |

### 3. Compliance Assessment

#### Assessment Areas
| Area | Questions to Ask |
|------|-----------------|
| Documentation | Is the process documented? |
| Training | Are people trained? |
| Execution | Is the process followed? |
| Monitoring | Is performance monitored? |
| Improvement | Is the process improved? |

#### Finding Classification
| Classification | Definition |
|---------------|------------|
| Conformity | Meets requirements |
| Nonconformity | Does not meet requirements |
| Opportunity | Potential for improvement |

### 4. Audit Reporting

#### Report Structure
1. Executive Summary
2. Audit Scope and Objectives
3. Process Description
4. Findings and Observations
5. Compliance Assessment
6. Recommendations
7. Action Plan

## Process Audit Standards

### International Standards
- **ISO 9001**: Process approach
- **ISO 19011**: Audit guidelines
- **CMMI**: Process maturity
- **ITIL**: IT service management

### Process Maturity Levels
| Level | Description |
|-------|-------------|
| 1 - Initial | Ad hoc processes |
| 2 - Managed | Planned and tracked |
| 3 - Defined | Standardized processes |
| 4 - Quantitatively Managed | Measured and controlled |
| 5 - Optimizing | Continuous improvement |

## Integration with Other Workflows

| Workflow | Integration Point |
|----------|------------------|
| Quality Audit | Audit quality processes |
| Internal Audit | Audit through internal audit |
| Configuration Audit | Audit configuration processes |
| Compliance Audit | Audit compliance processes |

## Best Practices
1. Map processes before auditing
2. Focus on process effectiveness
3. Verify process execution
4. Identify improvement opportunities
5. Follow up on corrective actions
6. Use process metrics
7. Involve process owners
