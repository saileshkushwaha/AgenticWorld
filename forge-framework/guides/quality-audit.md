# Quality Audit Guide - Forge Engineering Lifecycle Framework

## Overview
This guide provides procedures for conducting quality audits within the Forge framework. It covers quality management system evaluation, process assessment, and continuous improvement.

## Quality Audit Process

### 1. Audit Planning

#### Audit Types
| Type | Purpose | Standard |
|------|---------|----------|
| System Audit | QMS effectiveness | ISO 9001 |
| Process Audit | Process compliance | VDA 6.3 |
| Product Audit | Product quality | Customer requirements |
| Supplier Audit | Supplier quality | Supplier standards |

#### Audit Planning Steps
1. Define audit objectives
2. Determine audit scope
3. Identify audit criteria
4. Select audit team
5. Develop audit schedule
6. Prepare audit tools

### 2. Audit Execution

#### Audit Techniques
| Technique | Description | Application |
|-----------|-------------|-------------|
| Traceability | Following process flow | Process audits |
| Horizontal | Across processes | System audits |
| Vertical | Deep dive into one process | Process audits |
| Checklist | Predefined questions | All audits |

#### Evidence Evaluation
| Evidence Type | Reliability | Documentation |
|--------------|-------------|---------------|
| Documentary | High | Records, reports |
| Observational | Medium | Photos, videos |
| Testimonial | Low | Interview notes |
| Statistical | High | Data analysis |

### 3. Nonconformance Classification

| Classification | Definition | Action Required |
|---------------|------------|-----------------|
| Major NC | System failure | Immediate correction |
| Minor NC | Isolated incident | Corrective action |
| OFI | Improvement opportunity | Consider implementation |

### 4. Audit Reporting

#### Report Content
1. Audit summary
2. Detailed findings
3. Nonconformance reports
4. Opportunities for improvement
5. Corrective action requests
6. Follow-up requirements

## Quality Standards

- Control charts

## Best Practices
1. Use risk-based audit planning
2. Focus on process effectiveness
3. Verify corrective action implementation
4. Promote continuous improvement
5. Maintain auditor competence
6. Use objective evidence
7. Communicate findings constructively
